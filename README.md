<h2>Hi, I'm Ammar</h2>

<p><em>Android Developer</em></p>

I'm a software engineer in Jakarta, Indonesia. I build native Android apps in Kotlin, mostly for banking and payments. Right now I work on payment terminal (EDC/POS) apps at Bank Rakyat Indonesia, and I like projects where software talks to hardware.

## What I work on

- Android apps with Kotlin, Jetpack Compose, MVVM and Clean Architecture
- Payment apps: NFC, contactless cards, device SDKs, Bluetooth and USB
- Backend and middleware with Java Spring Boot and TypeScript
- Server-driven UI, where the backend decides what the app shows

## Currently working on

**[Blueprint](https://github.com/AmmarAlGhifary/blueprint)**: an Android library for server-driven UI. Your backend sends a JSON description of a screen, and Blueprint renders it as native Jetpack Compose. That lets you change a screen without shipping an app update. It's on Maven Central at version 0.1.0, and I'm working toward 1.0.

## Projects

- **[Blueprint](https://github.com/AmmarAlGhifary/blueprint)**: an Android library that turns JSON from a server into native Jetpack Compose screens. Published on Maven Central.
- **[CineStream](https://github.com/AmmarAlGhifary/cinestream-sdui)**: a movie app built on server-driven UI, with a [TypeScript backend](https://github.com/AmmarAlGhifary/cinestream-sdui-backend) deployed on Vercel.
